# Booleans ✅❌

A **boolean** is the value `true` or `false` -- _it can only be one of those two_. They have type `Bool`.

Those values can be accessed just by referencing them by name, similar to a variable. However, variables cannot be named `true` or `false`. And these are case-sensitive -- never `True` or `FALSE`. They're always lowercase!

A comparison returns a boolean; for example, `1 + 1 == 2` returns `true`, and `2 * 2 >= 10` returns `false`.
