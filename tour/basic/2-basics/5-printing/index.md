# Printing stuff from your code

We have not yet explained the statement that starts with `print`. That is a **function call** (which is an expression). The function being called is named `print`. What you want to print are in the parentheses after it.

But where is `print` defined? You don't define it -- it's a built-in function available to every Klar file.

Inside the parentheses, you can print any **expression**, including text in a string in quotation marks, a number, or a variable. Multiple values can be printed by separating them with commas.
