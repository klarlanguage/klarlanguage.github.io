# 👋 Welcome to the Klar language tour! 🐨

Welcome to the Klar programming language! We're glad you came here! 💚

If you new to programming, and Klar is your first programming language, don't worry -- this tour is also for you. Many of the things we'll teach you can be applied to other programming languages. For experienced programmers, we again want to thank you for your interest in Klar.

This whole tour is interactive, and can be run in your browser. You don't have to install Klar on your computer to complete this tour. The panel to the right can be used to type code, with the results or errors below it.

If you get stuck or confused at any point, or just have questions, you can ask in the [Klar discussions page on GitHub](https://github.com/ProCode-Software/klar/discussions/categories/q-a). If this tour has a problem or something incorrect, you can report it [here](https://github.com/klarlanguage/klarlanguage.github.io/issues).
